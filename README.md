# AxiomPrime

## Download

**[Download AxiomPrimeLauncher.exe](https://github.com/CukeManCZ/AxiomPrime_Releases/releases/latest/download/AxiomPrimeLauncher.exe)**

Run it and press **INSTALL**. The launcher downloads the game, keeps it up to date and shows the patch notes.
You don't need to install anything else.

- Windows 10/11, 64-bit
- The game is installed in `%LocalAppData%\AxiomPrime`
